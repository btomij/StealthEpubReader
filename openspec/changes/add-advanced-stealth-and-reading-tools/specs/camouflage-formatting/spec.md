## ADDED Requirements

### Requirement: 程式碼與系統 Log 偽裝外殼模式
The system SHALL 提供可即時切換的內文偽裝外殼格式（包含「無偽裝」、「系統執行 Log 偽裝模式」、「C# 程式碼註解偽裝模式」），自動將小說段落包裝於逼真的日誌時間戳記或程式碼結構中。

#### Scenario: 切換為系統 Log 偽裝外殼模式
- **WHEN** 使用者選擇「系統 Log 偽裝模式」（或按快捷鍵 `Ctrl+L` 循環切換偽裝格式）
- **THEN** 閱讀器內文每一段落自動加上如 `[17:10:05 INF] Worker[04]: ` 之日誌前綴，且切換過程保留當前章節閱讀位置

#### Scenario: 切換為 C# 程式碼註解偽裝外殼模式
- **WHEN** 使用者選擇「C# 程式碼註解偽裝模式」
- **THEN** 閱讀器內文自動穿插模擬的 C# 方法簽章並將小說段落轉為 `// ` 單行或區塊註解格式顯示
