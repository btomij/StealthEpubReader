## ADDED Requirements

### Requirement: 自動滾動巡航模式 (Auto-Scroll)
The system SHALL 提供可調整速度之自動滾動巡航模式（可透過快捷鍵或工具列按鈕啟停），按設定之每秒像素速率自動平滑向下捲動內文，並在觸發老闆鍵或開啟設定抽屜時自動暫停。

#### Scenario: 啟動自動滾動並調整速度
- **WHEN** 使用者點擊「自動滾動」按鈕（或按下 `F5`）並調整滾動速度滑桿
- **THEN** 閱讀器內文依設定速率自動平滑向下捲動，無需手動操作滑鼠滾輪或方向鍵

### Requirement: 滑鼠左鍵下一頁與右鍵上一頁翻頁控制
The system SHALL 支援在閱讀區點擊滑鼠左鍵翻至下一頁（含章節底端自動跨下一章）、點擊滑鼠右鍵翻至上一頁（含章節頂端自動跨上一章），並透過位移閾值判斷與「按住左鍵拖曳移動視窗」無縫共存。

#### Scenario: 點擊滑鼠左鍵翻下一頁與按住拖曳共存
- **WHEN** 使用者在閱讀區單純點擊（未拖曳）滑鼠左鍵放開
- **THEN** 閱讀器向下翻動一頁（若已在章節末尾則自動載入下一章開頭）；若按住左鍵並移動滑鼠超過閾值則直接拖曳移動視窗而不誤觸翻頁

#### Scenario: 點擊滑鼠右鍵翻上一頁
- **WHEN** 使用者在閱讀區點擊滑鼠右鍵
- **THEN** 閱讀器向上翻動一頁（若已在章節開頭則自動載入上一章末尾）
