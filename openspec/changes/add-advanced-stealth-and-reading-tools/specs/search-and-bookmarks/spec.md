## ADDED Requirements

### Requirement: 全書與章節關鍵字搜尋 (`Ctrl+F`)
The system SHALL 提供書內關鍵字搜尋面板（快捷鍵 `Ctrl+F`），支援跨章節檢索包含關鍵字之章節與段落摘要，點選搜尋結果即可直接跳轉至對應章節與段落位置。

#### Scenario: 輸入關鍵字跨章節搜尋並跳轉
- **WHEN** 使用者按下 `Ctrl+F` 開啟搜尋分頁，輸入關鍵字並點擊任一筆搜尋結果
- **THEN** 系統立即載入該筆結果所屬章節並自動捲動定位至該段落位置

### Requirement: 閱讀書籤標記與管理 (`Ctrl+D`)
The system SHALL 支援為每本書新增、檢視與刪除多個閱讀書籤（快捷鍵 `Ctrl+D` 快速新增書籤），記錄書籤所在章節、捲動比例、文字摘要與建立時間，點選書籤即可瞬間跳轉。

#### Scenario: 按下 Ctrl+D 快速新增書籤並跳轉
- **WHEN** 使用者在閱讀途中按下 `Ctrl+D` 新增書籤，稍後於書籤清單中點選該書籤
- **THEN** 系統保存包含當前文字摘要的書籤紀錄，並在點選時精準跳轉回該章節與捲動百分比位置
