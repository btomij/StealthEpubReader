# StealthEpubReader

以 C# (.NET 10 WPF) 打造、遵循 **OpenSpec** 規格驅動開發的極致輕量、防抓包桌面端 EPUB 閱讀器。

## 核心特色

- **全視窗任意位置拖曳與極簡無邊框**：點住小說內文或視窗任一非按鈕區域皆可直接拖移視窗，支援縮放至「單行狀態列」尺寸，雙擊內文可隱藏頂部微型工具列。
- **雙層獨立透明度**：**背景透明度 (`0%~100%`)** 與 **文字透明度 (`10%~100%`)** 完全分離；背景可設為 `0%` 全透明讓文字直接懸浮於 IDE 或 Excel 上，且仍支援滑鼠滾輪操作。
- **系統字型自由切換 & 上班保護色**：支援讀取所有 Windows 已安裝字型（置頂 `Consolas`、`Cascadia Mono`、`Microsoft JhengHei UI` 等），內建 6 組一鍵切換保護色（IDE 註解綠、IDE 終端機暗灰、Office 報表灰、深/淺色幽靈全透明、護眼羊皮紙）。
- **毫秒級全域老闆鍵 & 滑鼠離開自動隱形**：預設 `Alt + Q` 全域瞬隱/喚醒（零動畫延遲）、隱藏工作列與 `Alt+Tab` 圖示、低調系統匣控制，並支援「滑鼠移開自動 0% 透明隱形」。
- **零卡頓預載引擎 & 自動進度記憶**：採用 `VersOne.Epub` 章節懶加載與上下章背景預載快取，預設過濾所有圖片防穿幫；每本書獨立記錄章節與捲動百分比，啟動即自動續讀。
- **極簡無封面圖書館**：支援直接拖放 (`.epub` Drag & Drop) 匯入書籍、關鍵字搜尋與一鍵秒切書籍。

## 建置與執行

```powershell
dotnet build src/StealthEpubReader/StealthEpubReader.csproj -c Release
dotnet run --project src/StealthEpubReader/StealthEpubReader.csproj -c Release
```

## 快捷鍵一覽

| 快捷鍵 / 手勢 | 功能說明 |
| :--- | :--- |
| **`Alt + Q`** *(全域老闆鍵)* | 無論焦點在哪個軟體，1 毫秒瞬間隱藏 / 喚醒閱讀器 |
| **`Esc`** | 關閉抽屜面板；若在閱讀畫面則直接瞬間隱藏視窗 |
| **`Ctrl + B` / `Ctrl + T`** | 開啟極簡無封面「書庫清單」/「章節目錄 (TOC)」 |
| **`Ctrl + ,` 或 `F2`** | 開啟「字型、雙層透明度與保護色設定」面板 |
| **`滾輪` / `上下方向鍵`** | 平滑逐行捲動（到底或到頂繼續滾動自動跨章節） |
| **`左右方向鍵` / `空白鍵`** | 翻頁與跨章節切換（`[` 與 `]` 可直接跳上/下一章） |
| **`Ctrl + 滾輪`** | 即時放大 / 縮小字體大小 |
| **`Alt + 滾輪`** | 即時微調**文字透明度** |
| **`Shift + 滾輪`** | 即時微調**背景透明度**（調至 0% 即為全透明懸浮文字） |
| **按住視窗任一處左鍵** | 直接拖曳移動視窗（不限於頂部標題列） |
| **雙擊閱讀區內文** | 隱藏 / 顯示頂部微型工具列 |
