# StealthEpubReader

以 C# (.NET 10 WPF) 打造、遵循 **OpenSpec** 規格驅動開發的極致輕量、防抓包桌面端 EPUB 閱讀器。

## 核心特色

- **🛡️ 防螢幕分享與防截圖曝光 (`WDA_EXCLUDEFROMCAPTURE`)**：呼叫 Windows DWM 原生底層 API（預設開啟），在 Teams、Zoom、Google Meet、Discord 分享整個桌面或使用截圖工具時，**閱讀器視窗在別人的畫面上 100% 自動隱形透明**，只有自己的螢幕看得到。
- **💻 程式碼 / 系統 Log 偽裝外殼模式 (`Ctrl+L`)**：一鍵將小說段落即時包裝進逼真的「`.NET 系統執行 Log (`[INF] [T-08] OrderPipeline: ...`)`」或「`C# 類別方法與 // 註解結構`」，旁人走近細看也以為在看 Log 或寫程式。
- **🚨 老闆鍵雙模式：瞬間隱身 vs. 假報錯 StackTrace 畫面 (`Alt+Q`)**：老闆鍵除了 1 毫秒瞬間隱藏視窗外，也可設為「瞬間將小說替換成逼真的 `SqlException (0x80131904) StackTrace` 除錯畫面」，避免視窗突然消失引人起疑。
- **👻 滑鼠點擊穿透幽靈模式 (`Alt+G`)**：利用 `WS_EX_TRANSPARENT` 讓滑鼠點擊與滾輪直接穿透至底層的 Excel 或 VS Code；穿透期間可透過全域熱鍵 **`Alt + J` / `Alt + K`** 在不切換焦點的情況下控制閱讀器上下捲動。
- **⏱️ 自動滾動巡航模式 (`F5`)**：支援自訂每秒像素速率（5~120 px/s）自動平滑向下捲動，雙手無需頻繁滾動滾輪。
- **🔍 全書關鍵字搜尋 (`Ctrl+F`) & 多重書籤管理 (`Ctrl+D`)**：支援跨章節關鍵字搜尋並定位段落，以及一鍵新增/管理閱讀書籤。
- **🎨 雙層獨立透明度 & 系統字型自由切換**：背景透明度 (`0%~100%`) 與文字透明度 (`10%~100%`) 完全分離；支援所有 Windows 系統字型（置頂 `Consolas`、`Cascadia Mono`、`Microsoft JhengHei UI` 等）與 6 組上班保護色預設集。
- **✋ 全視窗任意位置按住拖曳**：點住小說內文或視窗任一非按鈕區域皆可直接拖移視窗。

## 建置與執行

```powershell
dotnet build src/StealthEpubReader/StealthEpubReader.csproj -c Release
dotnet run --project src/StealthEpubReader/StealthEpubReader.csproj -c Release
```

## 快捷鍵一覽

| 快捷鍵 / 手勢 | 功能說明 |
| :--- | :--- |
| **`Alt + Q`** *(全域老闆鍵)* | 1 毫秒瞬間隱藏/喚醒視窗，或瞬間切換「假報錯 StackTrace 畫面」 |
| **`Alt + G`** *(全域熱鍵)* | 開啟 / 解除「滑鼠點擊穿透幽靈模式」 |
| **`Alt + J` / `Alt + K`** *(全域熱鍵)* | 在滑鼠穿透或操作其他軟體時，無焦點控制閱讀器向下 / 向上滾動 |
| **`Ctrl + L`** | 循環切換內文偽裝外殼：`無偽裝` → `系統 Log` → `C# 程式碼註解` |
| **`F5`** | 開啟 / 暫停「自動平滑滾動巡航 (Auto-Scroll)」 |
| **`Ctrl + F`** | 開啟「全書關鍵字搜尋」面板 |
| **`Ctrl + D`** | 在目前閱讀位置快速新增書籤（右鍵點頂部 `+書籤` 可開啟書籤清單） |
| **`Ctrl + B` / `Ctrl + T`** | 開啟極簡「書庫清單」/「章節目錄 (TOC)」 |
| **`Ctrl + ,` 或 `F2`** | 開啟「外觀、字型、雙層透明度與終極防抓包設定」面板 |
| **`滾輪` / `上下方向鍵`** | 平滑逐行捲動（到底或到頂繼續滾動自動跨章節） |
| **`左右方向鍵` / `空白鍵`** | 翻頁與跨章節切換（`[` 與 `]` 可直接跳上/下一章） |
| **`Ctrl / Alt / Shift + 滾輪`** | 即時微調：字體大小 (`Ctrl`) / 文字透明度 (`Alt`) / 背景透明度 (`Shift`) |
| **按住視窗任一處左鍵** | 直接拖曳移動視窗（包含小說內文區，不限於標題列） |
| **雙擊閱讀區內文** | 隱藏 / 顯示頂部微型工具列 |
